# Такси ТАП! 🚕

Яндекс Go сыяктуу такси сервиси: **бардык иш сайтта**, Telegram бот номерди
ырастайт жана билдирүү жиберет гана. Такси роБОТтон өзүнчө долбоор.

| Бет | Ким үчүн |
|---|---|
| `/` | Жүргүнчү: карта, пин, «Кайда бара жатабыз?», баа, чакыруу, айдоочуну картадан көрүү, баалоо |
| `/driver` | Айдоочу: арыз (унаа + 3 документтин сүрөтү), линияга чыгуу, заказ (үн + 15 сек), сапар, баланс толуктоо (чек), тарых |
| `/admin` | Админ: карта жана көрсөткүчтөр, арыздар жана документтер, чектер, сапарлар, тарифтер |

## Кантип иштейт

**Аккаунт = телефон номери.** Бир номер жүргүнчү да, айдоочу да боло алат.

**Кирүү:** сайтта номер жазылат → `t.me/<бот>?start=web_<токен>` → ботто
«📱 Номеримди жөнөтүү» → сайт өзү ачылат. SMS акчасы жок. Бот ошол эле учурда
номерди Telegram аккаунтка байлайт — билдирүүлөр ошого барат.

**Бот** эки гана иш кылат:
1. Номер ырастоо
2. Кыска билдирүүлөр + «Сайтты ачуу» баскычы: айдоочуга «жаңы заказ»,
   жүргүнчүгө «айдоочу табылды / келди», админге «жаңы арыз / чек».
   Колдонуучу ботто же сайтта өчүрө алат.

Токен жок болсо да сайт иштей берет (билдирүүсүз, DEV кирүү менен).

**Dispatch:** заказ эң жакынкы бош айдоочуга 15 сек сунушталат; жооп жок →
кийинкисине. Радиус 3 км → 5 км → 8 км. 3 мүнөттө эч ким албаса — «айдоочу жок».
Бир заказды эки айдоочу ала албайт (атомдук `UPDATE ... WHERE status='searching'`).

**Баа:** `max(минимум, отуруу + км×a + мүн×b) × k`, 10 сомго тегеректелет;
`k` — талап коэффициенти (1.0–1.5). Аралык азырынча түз сызык × 1.3.

## Файлдар

| Файл | Эмне кылат |
|---|---|
| `core.py` | База (Postgres/SQLite), аккаунттар, гео, баа, сапардын абалдары, файлдар |
| `flow.py` | Аракеттер жана кимге кандай билдирүү кетери ("бир мээ") |
| `dispatch.py` | Заказды жакындан алыска карай сунуштоо |

| `bot.py` | Негизги процесс: сайт + dispatch + Telegram (ырастоо, билдирүү) |
| `strings.py` | Билдирүүлөрдүн тексттери (кыргызча / орусча) |
| `static/` | `rider.html`, `driver.html`, `admin.html` |
| `taxi_geo.py` | Облус/район тизмеси (кийинки этап: шаарлар аралык) |
| `tests/` | `test_flow.py` — сыноолор; `screens.py` — скриншоттор |

## Каржы

Админ → **Каржы**: комиссия (%), бекер мезгил (ушул күнгө чейин — андан кийин комиссия өзү күйөт),
минималдуу баланс; бүгүн / жума / ай боюнча комиссия жана жүгүртүү, акыркы 6 ай, айдоочулар боюнча.
Комиссия бүтүн сомго тегеректелип, сапар бүткөндө айдоочунун балансынан кармалат.
Айдоочу → **Менин кабинетим**: тарифи, балансы, бүгүн / жума / ай: сапар, жүгүртүү, комиссия, колунда калганы.

## Railway'де жайгаштыруу

1. `New Project` → `Deploy from GitHub repo` → ушул репо.
2. `+ New` → `Database` → `Add PostgreSQL`.
3. Кызматка **Volume** кошуу (документтер жана чектер үчүн), мис. `/data`.
4. Settings → Start command: `python bot.py`
5. Networking → **Generate Domain**.
6. Variables:

| Өзгөрмө | Маани |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather'ден |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `SITE_URL` | Railway берген домен, мис. `https://taxi-tap.up.railway.app` |
| `ADMIN_PHONES` | Админдин номери (бир нечеси үтүр менен) |
| `ADMIN_IDS` | (кошумча) Админдин Telegram ID'си |
| `PAY_INFO` | Толуктоо реквизити, мис. `MBank: +996 700 ... (Аты Ж.)` |
| `COMMISSION_PCT` / `MIN_BALANCE` | Баштапкы маани гана — андан кийин админ панелинин «Каржы» бөлүмүнөн башкарылат |
| `SERVICE_AREA` | Иштөө аймагы: демейки күйүк (Базар-Коргон району); `off` — бүт өлкө |
| `AREA_QUERY` / `AREA_CITY` / `AREA_NAME` | Аймак: OSM'деги аты (`Базар-Коргонский район`), тарифтин шаары, сайттагы аты |
| `TEST_SELF_ORDER` | `1` — бир номер өз заказын айдоочу катары ала алат (**сыноо үчүн гана**, иште алып салыңыз) |

`DATA_DIR` коюлбаса, Railway'дин Volume жолу (`RAILWAY_VOLUME_MOUNT_PATH`) өзү колдонулат.

## Жергиликтүү иштетүү

```bash
WEB_DEV_LOGIN=1 ADMIN_PHONES=0700123456 python web.py   # Telegram'сыз → http://localhost:8000
python -m unittest discover tests                        # сыноолор
python tests/screens.py                                  # скриншоттор (Playwright + Chrome)
```

`WEB_DEV_LOGIN=1` — номер ырастоосуз кирүү, **сыноо үчүн гана**; Railway'де койбоңуз.

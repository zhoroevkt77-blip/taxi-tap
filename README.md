# Такси ТАП! 🚕

Telegram аркылуу такси чакыруу: жүргүнчү чекитин жөнөтөт, заказ
**эң жакынкы бош айдоочуга** автоматтык түрдө кетет.

Такси роБОТтон өзүнчө долбоор. ТАП!тын «бир мээ, көп ооз» үлгүсү менен курулган.

## Файлдар

| Файл | Эмне кылат |
|---|---|
| `core.py` | Өзөк: база (Postgres/SQLite), гео, баа, сапардын абалдары |
| `flow.py` | «Бир мээ»: бардык сүйлөшүү логикасы, платформага көз каранды эмес |
| `dispatch.py` | Заказды жакындан алыска карай айдоочуларга сунуштоо |
| `bot.py` | Telegram «оозу» (сайтты да ушул процесс иштетет) |
| `web.py` | Сайт «оозу»: жүргүнчүнүн бети + JSON API |
| `static/rider.html` | Жүргүнчүнүн бети (`/`): карта, пин, баа, заказ, айдоочуну көзөмөлдөө |
| `static/driver.html` | Айдоочунун бети (`/driver`): линияга чыгуу, заказ, сапар, тарых |
| `static/admin.html` | Админ панели (`/admin`): карта, айдоочулар, толуктоо, сапарлар, тарифтер |
| `strings.py` | Кыргызча / орусча тексттер |
| `taxi_geo.py` | Облус/район тизмеси (кийинки этап: шаарлар аралык каттам) |
| `tests/` | Толук сценарийдин сыноолору |

## Кантип иштейт

**Жүргүнчү:** 🚕 Такси чакыруу → номер → 📍 кайдан → 🏁 кайда (же «айдоочуга өзүм айтам») → баа → ✅ Чакыруу.

**Айдоочу:** 🚗 Айдоочу болуу → номер, унаа, түсү, номери → админ ырастайт →
📎 → Location → **Share My Live Location** → онлайн. Заказ келет: ✅ Алам → 📍 Келдим → ▶️ Сапар башталды → 🏁 Бүттү.

**Dispatch:** радиус 3 км (1-мүнөт) → 5 км → 8 км. Ар айдоочуга 15 сек.
3 мүнөттө эч ким албаса, жүргүнчүгө «айдоочу жок» деп айтылат.
Бир заказды эки айдоочу ала албайт (базада атомдук `UPDATE ... WHERE status='searching'`).

**Баа:** `max(минимум, отуруу + км×a + мүн×b) × k`, 10 сомго тегеректелет.
`k` — талап коэффициенти (1.0–1.5). Аралык азырынча түз сызык × 1.3 (кийин OSRM/2GIS).

## Сайт (жүргүнчү)

Яндекс Go сыяктуу: толук экран карта, пинди жылдырып «кайдан», издөөдөн же
картадан «кайда», баа, «Чакыруу», айдоочу картада жакындап келет, баалоо.

- Карта: Leaflet + OpenStreetMap, дарек издөө: Nominatim (бекер, аз трафик үчүн)
- Кирүү: номер Telegram бот аркылуу ырасталат (SMS акчасыз):
  сайт → `t.me/<бот>?start=web_<токен>` → «Номеримди жөнөтүү» → сайтка кирди
- Абал ар 2 секундда `/api/ride` аркылуу жаңыланат

Сыноо (Telegram'сыз, номер ырастоосуз):

```bash
WEB_DEV_LOGIN=1 python web.py        # → http://localhost:8000
```

## Сайт (айдоочу) — `/driver`

- Кирүү: ботто айдоочу катары катталган номер → Telegram аркылуу ырастоо
- «Линияга чыгуу» → GPS ар 5 сек жиберилет; 60 сек жаңыртуу болбосо — офлайн
- Экран өчпөсүн деп Wake Lock колдонулат
- Заказ келгенде: үн + титирөө, 15 сек тегерек таймер, «Алам / Жок»
- Сапар: Чалуу, Навигатор (Google Maps), Келдим → Баштоо → Бүтүрүү
- Бүгүнкү киреше, баланс, рейтинг, сапарлардын тарыхы
- Балансты толуктоо азырынча бот аркылуу (скриншот → админ)

⚠️ Браузер фондо GPS жибербейт: айдоочу бетти ачык жана экранды күйүк кармашы керек.
Кийин TWA/Capacitor менен Android тиркемеге оролот.

## Админ панели — `/admin`

Кирүү: `ADMIN_IDS`теги Telegram аккаунттун номери → Telegram аркылуу ырастоо.

| Бөлүм | Эмне бар |
|---|---|
| Карта | Онлайн/бош/сапардагы айдоочулар, күтүп турган жүргүнчүлөр; бүгүнкү сапар, жүгүртүү, комиссия, «айдоочусуз калган» заказдар; активдүү заказды жокко чыгаруу |
| Айдоочулар | Жаңы арыздарды ырастоо/баш тартуу, бөгөттөө/ачуу, балансты кол менен ± өзгөртүү |
| Толуктоо | Айдоочу ботко жиберген чектин сүрөтү, сумма жазып кошуу же баш тартуу |
| Сапарлар | Акыркы 60 сапар: ким, кайсы айдоочу, баа, абалы, ким жокко чыгарды |
| Тарифтер | Ар шаардын отуруу / 1 км / 1 мүнөт / минимум баасы |

Ботко келген баскычтар (арыз, чек) да иштей берет — экөө бир базада.

## Railway'де жайгаштыруу

1. Жаңы долбоор → `Deploy from GitHub repo` → ушул репо.
2. `+ New` → `Database` → `Add PostgreSQL`.
3. Кызматтын Variables:

| Өзгөрмө | Маани |
|---|---|
| `TELEGRAM_BOT_TOKEN` | @BotFather'ден жаңы бот |
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}` |
| `ADMIN_IDS` | Сиздин Telegram ID (бир нечеси үтүр менен) |
| `COMMISSION_PCT` | Комиссия %, пилотто `0` |
| `MIN_BALANCE` | Ушундан аз болсо заказ келбейт (дефолт `0`) |

4. Settings → Start command: `python bot.py`
5. Networking → **Generate Domain** — сайт ушул даректе ачылат (PORT'ту Railway өзү берет)

## Админ буйруктары

- `/tarif Каракол 60 18 3 100` — шаардын тарифи: отуруу, 1 км, 1 мүнөт, минимум
- `/pending` — ырастоону күткөн айдоочулар
- `/stat` — онлайн айдоочулар жана сапарлар

Айдоочунун арызы жана баланс скриншоттору админге баскычтар менен келет.
